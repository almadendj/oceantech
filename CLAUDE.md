## Next.js 16 Breaking Changes to Know

Before writing any Next.js code, consult `node_modules/next/dist/docs/` for authoritative API docs.

Key differences from earlier versions:

- **`params` and `searchParams` are now Promises** — must be `await`ed in Server Components:
  ```tsx
  export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
    const { slug } = await params
  }
  ```
- **`PageProps` and `LayoutProps` are globally available** type helpers (no import needed), generated by `next dev`/`next build`/`next typegen`.
- **`next build` no longer runs the linter** — run `npm run lint` separately.
- **Turbopack** is the default dev bundler. Use `next dev --webpack` to opt out.
- **`next lint` CLI is removed** — use `eslint` directly (already reflected in `package.json`).

## Architecture

The project is in its initial scaffold state (single page, no custom routes yet).

- `app/layout.tsx` — root layout with Geist fonts, dark mode support
- `app/page.tsx` — home page (Server Component by default)
- `app/globals.css` — Tailwind v4 import + CSS custom properties for light/dark theme
- `public/` — static assets served from `/`

All components are Server Components by default. Add `'use client'` only when state, event handlers, lifecycle hooks, or browser APIs are needed.
